# חישוב נפח וכמות גז

אפליקציית אנדרואיד לחישוב נפח מוגן וכמות גז כיבוי (FM-200 / Novec 1230) בחדרים עם תקרות בגבהים שונים.

- כל דחיפה ל-`main` בונה APK אוטומטית (GitHub Actions) ומפרסמת אותו בעמוד Releases.
- להורדה: Releases ← הגרסה האחרונה ← `GasCalc.apk`.
- הדף עצמו נמצא ב-`app/src/main/assets/index.html`.

החישוב הוא כלי עזר. לפני תכנון והתקנה יש לבדוק מול הוראות היצרן והתקן.
